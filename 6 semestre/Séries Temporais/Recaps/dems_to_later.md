
# Quinto
A dinâmica estocástica do $AR(p)$ é governada pela equação de diferença estocástica. A solução geral para $y_t$ é a soma da solução particular (devida às inovações $\varepsilon_t$) com a solução homogênea da equação determinística:$$y_t - \phi_1 y_{t-1} - \phi_2 y_{t-2} - \dots - \phi_p y_{t-p} = 0$$Propondo uma solução do tipo $y_t^{(h)} = A \cdot z^{-t}$ e substituindo na equação homogênea:$$z^{-t} - \phi_1 z^{-(t-1)} - \phi_2 z^{-(t-2)} - \dots - \phi_p z^{-(t-p)} = 0$$Multiplicando toda a equação por $z^t$:$$1 - \phi_1 z - \phi_2 z^2 - \dots - \phi_p z^p = 0 \iff \phi(z) = 0$$Se $z_1, z_2, \dots, z_p$ são as $p$ raízes (complexas ou reais) de $\phi(z) = 0$, a solução homogênea é uma combinação linear dos modos de memória:$$y_t^{(h)} = \sum_{j=1}^{p} A_j \cdot z_j^{-t}$$Para que o processo seja estacionário (isto é, para que a memória dos choques passados se dilua no tempo e a variância não exploda quando $t \to \infty$), é necessário que cada modo $z_j^{-t}$ convirja para zero quando $t \to \infty$:$$\lim_{t \to \infty} |z_j^{-t}| = 0 \iff |z_j^{-1}| < 1 \iff |z_j| > 1 \quad \blacksquare$$

# Sexto
Para qualquer ordem de regressão $k > p$, a equação do processo real é:$$y_t = \phi_1 y_{t-1} + \dots + \phi_p y_{t-p} + 0 \cdot y_{t-p-1} + \dots + 0 \cdot y_{t-k} + \varepsilon_t$$Como $\varepsilon_t$ é não correlacionado com todos os lags passados, a projeção ortogonal de $y_t$ no subespaço gerado por $\{y_{t-1}, \dots, y_{t-k}\}$ atribui peso exatamente $\phi_j$ para os primeiros $p$ lags e peso rigorosamente zero para todos os lags $j > p$.Como $\phi_{kk}$ é o coeficiente associado ao último termo $y_{t-k}$, temos $\phi_{kk} = 0, \, \forall k > p \quad \blacksquare$

# Sétimo
Assuma $C = 0$.Variância ($\gamma(0)$): $$\gamma(0) = \mathbb{E}[y_t^2] = \mathbb{E}[(\varepsilon_t + \theta_1 \varepsilon_{t-1})^2] = \mathbb{E}[\varepsilon_t^2] + 2\theta_1 \mathbb{E}[\varepsilon_t \varepsilon_{t-1}] + \theta_1^2 \mathbb{E}[\varepsilon_{t-1}^2] = \sigma^2(1 + \theta_1^2)$$Autocovariância no Lag 1 ($\gamma(1)$): $$\gamma(1) = \mathbb{E}[y_t y_{t-1}] = \mathbb{E}[(\varepsilon_t + \theta_1 \varepsilon_{t-1})(\varepsilon_{t-1} + \theta_1 \varepsilon_{t-2})] = \theta_1 \mathbb{E}[\varepsilon_{t-1}^2] = \theta_1 \sigma^2$$Autocovariância nos Lags $h \ge 2$: Para $h \ge 2$, os pares $(\varepsilon_t, \varepsilon_{t-1})$ e $(\varepsilon_{t-h}, \varepsilon_{t-h-1})$ não compartilham nenhum choque comum, logo $\gamma(h) = 0$.Dividindo pela variância: $$\rho(h) = \begin{cases} 1, & \text{se } h = 0 \\ \frac{\theta_1}{1 + \theta_1^2}, & \text{se } h = 1 \\ 0, & \text{se } h \ge 2 \end{cases} \quad \blacksquare$$

# Oitavo
Sem perda de generalidade, assuma que a constante $C = 0$ (processo centrado na média). Escrevemos a somatória compacta do processo para o instante $t$ definindo $\theta_0 = 1$:$$Y_t = \sum_{j=0}^{q} \theta_j \varepsilon_{t-j}$$1. Cálculo da Autocovariância Geral $\gamma(h)$Por definição, a autocovariância no lag $h \ge 0$ é dada pela esperança do produto de duas observações separadas por $h$ passos no tempo:$$\gamma(h) = \mathbb{E}[Y_{t+h} Y_t] = \mathbb{E} \left[ \left( \sum_{j=0}^{q} \theta_j \varepsilon_{t+h-j} \right) \left( \sum_{k=0}^{q} \theta_k \varepsilon_{t-k} \right) \right]$$Pela linearidade da esperança, podemos expandir o produto das duas somas em uma soma dupla:$$\gamma(h) = \sum_{j=0}^{q} \sum_{k=0}^{q} \theta_j \theta_k \, \mathbb{E}[\varepsilon_{t+h-j} \varepsilon_{t-k}]$$Como os ruídos $\varepsilon_t$ formam um ruído branco não-correlacionado ($\mathbb{E}[\varepsilon_r \varepsilon_s] = 0$ para $r \neq s$ e $\mathbb{E}[\varepsilon_r^2] = \sigma^2$), a esperança $\mathbb{E}[\varepsilon_{t+h-j} \varepsilon_{t-k}]$ é não-nula se e somente se os índices dos ruídos forem idênticos:$$t + h - j = t - k \iff k = j - h$$2. Análise para o Caso $h > q$ (Lags Superiores à Ordem $q$)Analisamos os limites dos índices para qualquer lag $h > q$:O índice $j$ varia no intervalo finito $j \in \{0, 1, \dots, q\}$, o que implica que $j \le q$.Como $h > q$, temos que $j - h \le q - h < 0$.Logo, para qualquer valor de $j \in \{0, \dots, q\}$, a condição de igualdade exige que $k = j - h < 0$.No entanto, o índice $k$ pertence estritamente ao conjunto $k \in \{0, 1, \dots, q\}$ (ou seja, exige-se $k \ge 0$).Como não existe nenhum par de índices $(j, k) \in \{0, \dots, q\}^2$ que satisfaça simultaneamente a igualdade $t + h - j = t - k$ quando $h > q$, todos os termos do produto cruzado na esperança se anulam:$$\mathbb{E}[\varepsilon_{t+h-j} \varepsilon_{t-k}] = 0, \quad \forall j, k \in \{0, \dots, q\} \quad \text{quando } h > q$$Consequentemente, a autocovariância no lag $h > q$ é rigorosamente nula:$$\gamma(h) = 0, \quad \forall h > q$$3. Conclusão da ACF $\rho(h)$Dividindo a autocovariância $\gamma(h)$ pela variância do processo $\gamma(0)$:$$\rho(h) = \frac{\gamma(h)}{\gamma(0)} = \frac{0}{\gamma(0)} = 0, \quad \forall h > q \quad \blacksquare$$
